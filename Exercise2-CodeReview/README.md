# Exercise 2 — Code Review (~20 minutes)

A teammate has opened **PR #142** (in [`PR-142-Favorites/`](PR-142-Favorites/)) and asked you to review it.
Start with the PR description in [`PR-142-Favorites/README.md`](PR-142-Favorites/README.md), then read the three Swift files.

Review it the way you would a real PR on your team. Talk us through:

- What would you comment on, and why?
- Which comments would **block** merging, and which are suggestions or nits?
- For the most important issues, how would you fix them?
- Is there anything you'd want to ask the author, or that's missing from the PR?

There's no need to compile or run this code, and it's fine not to get through everything. We care more about
how you prioritize and communicate than about finding every last issue.
